# Influence of the Geometry on the Mechanical Performance of Tubular Interlockings: A Study of the Sine Block

This repository contains the analysis scripts used to reproduce the results presented in the publication:

Macek, D., Weiß, M., Akpanya, R., Brepols, T., Holthusen, H. & Niemeyer, A.C. (2026). *Influence of the Geometry on the Mechanical Performance of Tubular Interlockings: A Study of the Sine Block*. Manuscript submitted for publication.

The code is organized into directories corresponding to the different geometries and the scripts used to generate the figures in the publication.

---

## Scripts Overview

* **`analysis_sinus/`**
  Contains all scripts required to reproduce the results related to the **Sine Block geometry** presented in the publication.

* **`analysis_hexagon/`**
  Contains the scripts used to reproduce the results related to the **Hexagon-based Block geometry**.

* **`figures/`**
  Contains the scripts and helper functions used to generate the **figures appearing in the publication**.
